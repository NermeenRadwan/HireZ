# HireZ - Smart Hiring Platform

A modern, AI-powered Applicant Tracking System (ATS) built with HTML5, CSS3, and JavaScript. HireZ streamlines the hiring process with intelligent candidate matching, automated resume parsing, and comprehensive interview management.

## 🚀 Features

### Core Functionality
- **AI-Powered Candidate Matching** - Advanced algorithms match candidates to job requirements with 95% accuracy
- **Smart Resume Parsing** - Automatically extract and organize candidate information from resumes in any format
- **Interview Management** - Schedule, conduct, and track candidate interviews with integrated video calling
- **Feedback System** - Collect and manage feedback from interviews and candidate interactions
- **Analytics Dashboard** - Track hiring metrics, time-to-hire, and candidate pipeline with detailed analytics
- **User Management** - Secure authentication and role-based access control

### Pages
- **Landing Page** (`index.html`) - Modern hero section with feature highlights
- **Authentication** (`login.html`, `register.html`) - Secure user authentication
- **Dashboard** (`dashboard.html`) - Comprehensive overview with charts and statistics
- **ATS** (`ats.html`) - Candidate management with pipeline visualization
- **Interview** (`interview.html`) - Interview scheduling and management
- **Upload** (`upload.html`) - Resume upload and parsing functionality
- **Feedback** (`feedback.html`) - Feedback collection and management
- **Profile** (`profile.html`) - User profile and settings
- **About** (`about.html`) - Company information and team
- **Error** (`error.html`) - Custom 404 error page

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **UI Framework**: Bootstrap 5.3.0
- **Icons**: Font Awesome 6.4.0
- **Charts**: Chart.js
- **Styling**: Custom CSS with CSS Variables
- **Responsive Design**: Mobile-first approach

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Local web server (optional, for development)

### Installation
1. Clone or download the project
2. Open `index.html` in your web browser
3. For development, use a local web server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx http-server
   
   # Using PHP
   php -S localhost:8000
   ```

### Usage
1. **Landing Page**: Start at `index.html` to explore the platform
2. **Registration**: Create an account via `register.html`
3. **Login**: Access the dashboard via `login.html`
4. **Dashboard**: View analytics and manage hiring pipeline
5. **ATS**: Manage candidates and track applications
6. **Interviews**: Schedule and conduct interviews
7. **Upload**: Upload and parse candidate resumes
8. **Feedback**: Collect and manage interview feedback
